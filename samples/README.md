# samples/

Put local captures (`.pcapng`) and decoded JSON dumps here while you work.

**Everything in this folder except this README is git-ignored, and `*.pcapng` is ignored everywhere in the repo.**
Captures can contain account tokens and private chat. They must never be committed, uploaded, or attached to issues.
See [ADR 0004](../docs/adr/0004-raw-pcapng-never-leaves-the-pc.md).
